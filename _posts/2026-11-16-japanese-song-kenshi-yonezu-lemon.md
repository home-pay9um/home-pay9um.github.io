> 요네즈 켄시(米津玄師)의 「Lemon」을 들으면서 가사에 나오는 단어와 문법을 정리한 일본어 학습 노트이다.

이 곡에는 가정, 가능, 수수 표현, 명사 수식 같은 초·중급 문법이 고르게 들어 있어서 한 곡만 꼼꼼히 읽어도 배울 것이 많다.

가사는 저작권이 있는 저작물이므로 이 글에는 **가사와 가사의 번역을 싣지 않는다.** 단어는 사전형으로, 문법은 직접 만든 예문으로 설명한다. 공식 뮤직비디오와 가사 페이지를 옆에 띄워 놓고 읽으면 된다.

## 2. 가사의 표기 {#notation}

### 2.1 구자체로 적힌 가사를 조심한다

인터넷에 올라온 가사 중에는 한자가 **구자체**(旧字体)로 바뀌어 있는 것이 있다. 구자체는 한국에서 쓰는 한자와 모양이 같아서 오히려 익숙하게 느껴지지만, 현대 일본어는 획을 줄인 **신자체**(新字体)를 쓴다. 이 곡의 공식 가사도 모두 신자체이다.

| 구자체 | 신자체 | 이 곡의 단어 | 읽기 |
| :--: | :--: | :-- | :-- |
| 拂 | 払 | 払う | はらう |
| 戾 | 戻 | 戻る | もどる |
| 敎 | 教 | 教える | おしえる |
| 隱 | 隠 | 隠す | かくす |
| 殘 | 残 | 残る | のこる |
| 歸 | 帰 | 帰る | かえる |
| 覺 | 覚 | 覚える | おぼえる |
| 淚 | 涙 | 涙 | なみだ |
| 橫 | 横 | 横顔 | よこがお |
| 戀 | 恋 | 恋 | こい |
| 噓 | 嘘 | 嘘 | うそ |
| 實 | 実 | 果実 | かじつ |
| 樣 | 様 | 様 | よう |

> 한국식 한자에 익숙할수록 신자체를 따로 익혀야 한다. 사전을 찾거나 일본어로 입력할 때는 신자체를 써야 원하는 단어가 나온다.
>
> 嘘만은 예외로, 상용한자가 아니어서 일본 책에서도 噓로 인쇄된 것을 볼 수 있다. 화면에서는 嘘가 훨씬 흔하다.
{: .prompt-tip }

### 2.2 작사가가 고른 표기

가사에는 뜻은 같아도 분위기를 위해 평소와 다르게 적은 단어가 있다. 사전에서 찾을 때는 흔히 쓰는 표기로 찾는다.

| 가사의 표기 | 흔히 쓰는 표기 | 읽기 | 메모 |
| :-- | :-- | :-- | :-- |
| 昏い | 暗い | くらい | 昏은 黄昏(たそがれ, 황혼)의 글자이다 |
| 淋しさ | 寂しさ | さびしさ | 뜻은 같고 가사·소설에서 즐겨 쓴다 |
| みる | 見る | みる | 히라가나로 적었다 |
| くれ | 暮れ | くれ | 涙に暮れる의 暮れる이다 |
| わたし | 私 | わたし | 히라가나로 적었다 |
| 様な, 様に | ような, ように | よう | 보통은 히라가나로 적는다 |
| 未だに | いまだに | いまだに | 히라가나로도 많이 적는다 |
| 側 | そば | そば | がわ(~쪽)로도 읽는 글자이다 |

昏과 淋은 상용한자표에 없는 글자이다. 시험이나 공문서에서는 暗い, 寂しい로 적는다.

## 3. 구간별 단어장 {#vocabulary}

단어는 사전형으로 적었다. 품사의 표기는 다음과 같다.

| 표기 | 뜻 | 활용 예 |
| :-- | :-- | :-- |
| 동사1 | 1그룹 동사(5단 동사) | 言う → 言わない, 言って |
| 동사2 | 2그룹 동사(1단 동사) | 見る → 見ない, 見て |
| 동사3 | 3그룹 동사(する, 来る) | する → しない, して |

> る로 끝나고 그 앞이 い단·え단인 동사는 대부분 2그룹이지만, 이 곡에 나오는 **帰る·知る·切る는 1그룹**이다.
>
> 帰らない, 知らない, 切らない처럼 활용한다.
{: .prompt-warning }

## 4. 문법 {#grammar}

예문은 가사가 아니라 이 글을 위해 만든 문장이다. 되도록 3장의 단어로 만들었고, 단어장에 없는 한자에는 읽는 법을 달았다.

설명에 쓰는 용어는 다음과 같다.

| 용어 | 뜻 | 忘れる | 帰る |
| :-- | :-- | :-- | :-- |
| 사전형 | 사전에 실리는 기본형 | 忘れる | 帰る |
| ます형 어간 | ます형에서 ます를 뗀 형태 | 忘れ | 帰り |
| て형 | 문장을 잇는 형태 | 忘れて | 帰って |
| た형 | 과거·완료 | 忘れた | 帰った |
| ない형 | 부정 | 忘れない | 帰らない |

**보통형**은 사전형·た형·ない형처럼 です, ます를 붙이지 않은 형태를 묶어 부르는 말이다.

### 4.1 가정과 아쉬움

#### なら(ば) : ~라면

명사와 な형용사 어간에는 바로 붙고, 동사와 い형용사에는 보통형에 붙는다. ならば가 원래 형태이고 회화에서는 ば를 떼고 なら로 쓴다.

雨なら、<ruby>家<rt>いえ</rt></ruby>にいる。
: 비가 온다면 집에 있겠다.

帰るなら、今だ。
: 돌아갈 거라면 지금이다.

#### 가정 + よかった : ~였으면 좋았을 텐데

～ば, ～なら, ～たら 같은 가정 뒤에 よかった가 오면 '실제로는 그렇지 않았다'는 아쉬움을 나타낸다. 여기에 どれほど나 どんなに(얼마나)와 でしょう·だろう가 더해지면 '얼마나 좋았을까' 하는 탄식이 된다. 이때의 でしょう는 앞일을 짐작하는 말이 아니다.

もっと<ruby>早<rt>はや</rt></ruby>く言えばよかった。
: 더 일찍 말할 걸 그랬다.

あの日に戻れたら、どんなにいいだろう。
: 그날로 돌아갈 수 있다면 얼마나 좋을까.

#### ～なければ → ～なきゃ : ~하지 않으면

ない형의 ない를 なければ로 바꾸면 부정의 가정이 되고, 회화에서는 なきゃ로 줄여 말한다. いる는 いない → いなければ → いなきゃ가 된다.

言わなきゃ、わからない。
: 말하지 않으면 모른다.

<ruby>傘<rt>かさ</rt></ruby>がなきゃ、帰れない。
: 우산이 없으면 돌아갈 수 없다.

> 문장 끝에 오는 ～なきゃ는 ～なければならない(~해야 한다)를 줄인 말이다.
>
> 「もう帰らなきゃ。」는 '이제 돌아가야 해'라는 뜻이다.
{: .prompt-info }

### 4.2 명사를 꾸미는 말

일본어에는 관계대명사가 없다. 꾸미는 말이 아무리 길어도 보통형 그대로 명사 **앞**에 놓는다.

#### 동사 た형 + 명사 : ~한

出会った日
: 만난 날

<ruby>先生<rt>せんせい</rt></ruby>が教えてくれた<ruby>歌<rt>うた</rt></ruby>
: 선생님이 가르쳐 준 노래

古びる(낡다)처럼 변화를 나타내는 동사의 た형은 과거가 아니라 **지금의 상태**를 나타낸다.

古びた<ruby>本<rt>ほん</rt></ruby>
: 낡은 책

#### 동사 ない형 + 명사 : ~하지 않는

知らない<ruby>人<rt>ひと</rt></ruby>
: 모르는 사람

<ruby>止<rt>や</rt></ruby>まない雨
: 그치지 않는 비

#### 수식절 안의 が → の

명사를 꾸미는 절 안에서는 주어의 が를 の로 바꿀 수 있다. 이 の를 '~의'로 읽으면 뜻이 어긋난다.

わたしが知らない<ruby>人<rt>ひと</rt></ruby> = わたしの知らない<ruby>人<rt>ひと</rt></ruby>
: 내가 모르는 사람

雨が降る日 = 雨の降る日
: 비가 내리는 날

#### 형용사 + 명사

| 종류 | 만드는 법 | 예 | 뜻 |
| :-- | :-- | :-- | :-- |
| い형용사 | 그대로 붙인다 | 苦い<ruby>薬<rt>くすり</rt></ruby> | 쓴 약 |
| な형용사 | 어간 + な | 確かな<ruby>話<rt>はなし</rt></ruby> | 확실한 이야기 |
| 同じ | な 없이 붙인다 | 同じ夢 | 같은 꿈 |
| 同じような | 그대로 붙인다 | 同じような夢 | 비슷한 꿈 |

### 4.3 명사로 만들기

#### 보통형 + こと : ~하는 것

문장을 통째로 명사로 만들어서 を, が, は를 붙일 수 있게 한다.

<ruby>人<rt>ひと</rt></ruby>を愛することを知った。
: 사람을 사랑하는 것을 알았다.

#### 사람 + のこと : ~에 관한 것

思う, 忘れる, 知る처럼 생각이나 감정을 나타내는 말의 대상이 사람일 때 자주 붙인다. 겉모습만이 아니라 그 사람에 관한 모든 것을 가리키며, 한국어로 옮길 때는 대개 생략한다.

<ruby>母<rt>はは</rt></ruby>のことを思う。
: 어머니를 생각한다.

<ruby>彼<rt>かれ</rt></ruby>のことが<ruby>好<rt>す</rt></ruby>きだ。
: 그를 좋아한다.

#### ～のは～だ : ~한 것은 ~이다

강조하고 싶은 말을 뒤로 빼는 문형이다. の가 '것'의 역할을 한다.

残ったのは思い出だけだ。
: 남은 것은 추억뿐이다.

#### 형용사와 동사에서 나온 명사

| 만드는 법 | 예 | 느낌 |
| :-- | :-- | :-- |
| い형용사 어간 + さ | 寂しい → 寂しさ, 苦い → 苦さ | 정도, 성질 |
| い형용사 어간 + み | 悲しい → 悲しみ, 苦しい → 苦しみ | 그 감정 자체 |
| 동사 ます형 어간 | 願う → 願い, 帰る → 帰り | 그 동작, 결과 |

悲しみ와 苦しみ는 동사 悲しむ, 苦しむ의 ます형 어간이 명사가 된 것으로 볼 수도 있다. 이 곡의 匂い와 光도 동사 匂う(냄새가 나다), 光る(빛나다)에서 나온 명사이다.

### 4.4 て형으로 만드는 표현

#### ～ている, ～ていた

| 쓰임 | 예 | 뜻 |
| :-- | :-- | :-- |
| 진행 | 雨が降っている | 비가 내리고 있다 |
| 결과의 상태 | 覚えている, 知っている | 기억하고 있다, 알고 있다 |
| 과거의 진행·지속 | <ruby>待<rt>ま</rt></ruby>っていた | 기다리고 있었다 |

회화와 가사에서는 い를 빼고 말한다. ～ている는 ～てる, ～ていた는 ～てた가 된다. 이 곡의 隠してた와 愛してた가 그 예이다.

#### ～てくれる : (남이 나에게) ~해 주다

주고받는 방향에 따라 세 가지를 구분한다.

| 표현 | 방향 | 예 | 뜻 |
| :-- | :-- | :-- | :-- |
| ～てくれる | 남 → 나 | <ruby>友<rt>とも</rt></ruby>だちが教えてくれた | 친구가 가르쳐 주었다 |
| ～てあげる | 나 → 남 | <ruby>友<rt>とも</rt></ruby>だちに教えてあげた | 친구에게 가르쳐 주었다 |
| ～てもらう | 나 ← 남 | <ruby>友<rt>とも</rt></ruby>だちに教えてもらった | 친구에게 배웠다 |

～てくれる에는 상대의 행동을 고맙게 받아들이는 마음이 담긴다.

#### ～てください : ~해 주세요

정중한 부탁이다. どうか(부디)를 앞에 두면 간절함이 더해진다.

どうか<ruby>許<rt>ゆる</rt></ruby>してください。
: 부디 용서해 주세요.

#### ～てやまない : 계속 ~하다

원래는 願う, 愛する 같은 감정 동사에 붙어 '~해 마지않다'라는 뜻으로 쓰는 글말 표현이다. やまない는 止む(그치다)의 부정이므로 글자 그대로는 '~해서 그치지 않는다'가 된다. 이 곡에서는 溢れる에 붙어 글자 그대로의 뜻에 가깝게 쓰였다.

あなたの幸せを願ってやまない。
: 당신의 행복을 바라 마지않는다.

### 4.5 가능 표현

#### 가능형 만들기

| 그룹 | 만드는 법 | 예 |
| :-- | :-- | :-- |
| 동사1 | 끝의 う단을 え단으로 바꾸고 る | 帰る → 帰れる, 言う → 言える |
| 동사2 | る를 られる로 | 忘れる → 忘れられる |
| 동사3 | 불규칙 | する → できる, <ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>こ</rt></ruby>られる |

가능형은 동사2처럼 활용한다. 단순한 부정과 가능의 부정은 뜻이 다르므로 구분해서 읽는다.

| 단순 부정 | 가능 부정 |
| :-- | :-- |
| 帰らない (돌아가지 않는다) | 帰れない (돌아갈 수 없다) |
| 言わない (말하지 않는다) | 言えない (말할 수 없다) |
| 忘れない (잊지 않는다) | 忘れられない (잊을 수 없다) |

#### 명사 + ができる : ~을 할 수 있다

できる의 대상에는 を가 아니라 が를 쓴다.

<ruby>料理<rt>りょうり</rt></ruby>ができる。
: 요리를 할 수 있다.

#### ます형 어간 + きる, きれない : 다 ~하다, 다 ~할 수 없다

きる는 '끝까지 다 하다', きれない는 '끝까지 다 할 수 없다'라는 뜻을 더한다. 受け止める에 붙은 受け止めきれない는 '다 받아 낼 수 없다', 곧 '감당할 수 없다'가 된다.

<ruby>食<rt>た</rt></ruby>べきれない。
: 다 먹을 수 없다.

<ruby>数<rt>かぞ</rt></ruby>えきれない思い出
: 다 셀 수 없는 추억

### 4.6 부정과 강조

#### ない형 어간 + ずに : ~하지 않고

～ないで의 글말 표현이다. ない형에서 ない를 떼고 ずに를 붙인다. する만 せずに가 된다.

何も言わずに帰った。
: 아무 말도 하지 않고 돌아갔다.

가능형에 붙으면 '~하지 못한 채'가 된다. 言える에 붙은 言えずに는 '말하지 않고'가 아니라 '말하지 못한 채'이다.

#### ます형 어간 + はしない : 결코 ~하지 않는다

동사를 ます형 어간과 する로 나누고 그 사이에 は를 넣어 부정을 강조한다. ある는 ありはしない가 되고 '있을 리 없다'는 뜻이다.

忘れはしない。
: 결코 잊지 않는다.

#### 부정과 짝을 이루는 부사

| 표현 | 뜻 | 예 | 예의 뜻 |
| :-- | :-- | :-- | :-- |
| これ以上 ～ない | 더 이상 ~않다 | これ以上<ruby>待<rt>ま</rt></ruby>てない | 더는 기다릴 수 없다 |
| もう ～ない | 이제 ~않다 | もう<ruby>泣<rt>な</rt></ruby>かない | 이제 울지 않는다 |
| とても ～ない | 도저히 ~못 하다 | とても言えない | 도저히 말할 수 없다 |

とても는 긍정문에서는 '매우'이지만 부정과 만나면 '도저히'가 된다.

### 4.7 때, 정도, 비교

#### 사전형 + たび(に) : ~할 때마다

この<ruby>歌<rt>うた</rt></ruby>を<ruby>聞<rt>き</rt></ruby>くたびに、あの日を<ruby>思<rt>おも</rt></ruby>い<ruby>出<rt>だ</rt></ruby>す。
: 이 노래를 들을 때마다 그날이 떠오른다.

#### 사전형 + まで(は) : ~할 때까지(는)

は가 붙으면 '그때까지는 안 된다'는 한정의 느낌이 더해진다.

<ruby>仕事<rt>しごと</rt></ruby>が<ruby>終<rt>お</rt></ruby>わるまでは、<ruby>休<rt>やす</rt></ruby>めない。
: 일이 끝날 때까지는 쉴 수 없다.

#### 보통형 + ほど(に) : ~할 정도로

涙が<ruby>出<rt>で</rt></ruby>るほど<ruby>笑<rt>わら</rt></ruby>った。
: 눈물이 날 정도로 웃었다.

#### 보통형 + より : ~보다

思ったより苦い。
: 생각보다 쓰다.

#### ～まま : ~한 채, ~그대로

앞에 오는 말에 따라 붙이는 방법이 다르다.

| 앞에 오는 말 | 예 | 뜻 |
| :-- | :-- | :-- |
| 명사 + の | あの日のまま | 그날 그대로 |
| い형용사 | <ruby>冷<rt>つめ</rt></ruby>たいまま | 차가운 채 |
| な형용사 + な | <ruby>静<rt>しず</rt></ruby>かなまま | 조용한 채 |
| 동사 た형 | <ruby>電気<rt>でんき</rt></ruby>をつけたまま | 불을 켠 채 |

#### ～ように : ~처럼, ~대로

| 쓰임 | 만드는 법 | 예 | 뜻 |
| :-- | :-- | :-- | :-- |
| 비유 | 동사 보통형 + ように | <ruby>眠<rt>ねむ</rt></ruby>るように | 잠들듯이 |
| 비유 | 명사 + のように | <ruby>子<rt>こ</rt></ruby>どものように | 아이처럼 |
| 뜻대로 | 思うように | 思うように<ruby>書<rt>か</rt></ruby>けない | 마음대로 써지지 않는다 |

思うように는 뒤에 부정이 와서 '마음먹은 대로 되지 않는다'는 뜻으로 자주 쓴다.

#### まるで ～みたい : 마치 ~같다

みたい는 ようだ의 회화체이다. 명사에 바로 붙는다는 점이 のようだ와 다르다.

まるで<ruby>子<rt>こ</rt></ruby>どもみたいだ。
: 마치 아이 같다.

### 4.8 조사

| 조사 | 뜻 | 예 | 예의 뜻 |
| :-- | :-- | :-- | :-- |
| さえ | ~조차 | <ruby>名前<rt>なまえ</rt></ruby>さえ知らない | 이름조차 모른다 |
| など | ~따위, ~같은 것 | わたしなど | 나 같은 것 |
| だけ | ~만, ~뿐 | <ruby>一<rt>ひと</rt></ruby>つだけ | 하나만 |
| のに | ~인데도 | <ruby>約束<rt>やくそく</rt></ruby>したのに | 약속했는데도 |
| とともに | ~와 함께 | <ruby>家族<rt>かぞく</rt></ruby>とともに | 가족과 함께 |
| で | ~인 모습으로 | <ruby>笑顔<rt>えがお</rt></ruby>で | 웃는 얼굴로 |
| の (문장 끝) | 부드러운 질문 | どこに<ruby>行<rt>い</rt></ruby>くの？ | 어디 가? |

- など를 자신에게 쓰면 자신을 낮추는 말이 되고, 뒤에는 부정이 자주 온다.
- のに에는 기대와 다른 결과에 대한 아쉬움이 담긴다.
- とともに는 と一緒に(といっしょに)의 글말 표현이다.

#### に의 여러 쓰임

| 쓰임 | 예 | 뜻 |
| :-- | :-- | :-- |
| 있는 곳 | 側にいる | 곁에 있다 |
| 감정의 대상 | ～に恋をする | ~을 사랑하다 |
| 이동의 목적 | 取りに<ruby>行<rt>い</rt></ruby>く | 가지러 가다 |
| 꿈이나 마음속 | 夢に見る, 胸に残る | 꿈에 보다, 가슴에 남다 |
| 부사 만들기 | 鮮明に, 永遠に, 最後に | 선명하게, 영원히, 마지막에 |

이동의 목적은 **ます형 어간 + に + 이동 동사**로 나타낸다. 이동 동사 자리에는 行く, 来る, 帰る가 온다.

### 4.9 가사에서 자주 보는 문장

#### ます형 어간으로 문장 잇기

글말에서는 て형 대신 ます형 어간으로 문장을 잇는다. 이 곡에서는 残る가 残り로, 暮れる가 暮れ로 나온다.

雨が降り、<ruby>風<rt>かぜ</rt></ruby>が<ruby>吹<rt>ふ</rt></ruby>く。
: 비가 내리고 바람이 분다.

#### 복합동사

ます형 어간에 다른 동사를 붙여 한 단어로 만든다.

| 구성 | 복합동사 | 읽기 | 뜻 |
| :-- | :-- | :-- | :-- |
| 降る + 止む | 降り止む | ふりやむ | 내리던 것이 그치다 |
| 受ける + 止める | 受け止める | うけとめる | 받아 내다 |
| 切る + 分ける | 切り分ける | きりわける | 잘라 나누다 |

#### 명사로 끝나는 문장

가사와 시에서는 だ, です를 붙이지 않고 명사로 문장을 끝내서 여운을 남긴다.

<ruby>明日<rt>あした</rt></ruby>は<ruby>休<rt>やす</rt></ruby>み。
: 내일은 휴일.

#### 도치와 행 걸침

가사는 서술어를 먼저 말하고 꾸미는 말이나 대상을 뒤에 두는 일이 많다.

<ruby>行<rt>い</rt></ruby>こう、<ruby>海<rt>うみ</rt></ruby>へ。
: 가자, 바다로.

또 한 문장이 여러 행에 걸친다. 행이 다음과 같은 말로 끝나면 문장이 끝난 것이 아니므로 앞뒤의 행과 이어서 읽는다.

| 행의 끝 | 이어지는 방식 |
| :-- | :-- |
| ～ように | 앞이나 뒤의 동작을 꾸민다 |
| ～ことを | 뒤에 오는 동사의 목적어가 된다 |
| ～も, ～さえ | 뒤에 서술어가 온다 |
| ～なら | 조건이다. 뒤에 결론이 온다 |
| ～ほどに | 정도이다. 뒤의 내용이 그만큼이라는 뜻이다 |
| 명사 + に, で | 도치이다. 앞 행의 서술어에 걸린다 |

## 5. 해석할 때 헷갈리기 쉬운 부분 {#pitfalls}

### 5.1 뜻을 잘못 잡기 쉬운 표현

| 표현 | 틀리기 쉬운 해석 | 바른 해석 |
| :-- | :-- | :-- |
| よかったでしょう | 좋았을 것입니다 | 좋았을까 (아쉬움) |
| いなきゃ | 없었다면 | 없으면 |
| 言えずに | 말하지 않고 | 말하지 못한 채 |
| 帰れない | 돌아가지 않는다 | 돌아갈 수 없다 |
| 忘れられない | 잊지 않는다 | 잊을 수 없다 |
| とても ～ない | 매우 ~하지 않다 | 도저히 ~할 수 없다 |
| 思うように ～ない | 예전처럼 ~하지 못한다 | 마음대로 ~되지 않는다 |
| ～ていたの | ~하고 있을까 | ~하고 있었어? |
| あの日 | 저 날 | 그날 |

### 5.2 ～に恋をする의 に

恋をする의 상대는 を가 아니라 に로 나타낸다. '~에게'로 옮기면 어색하고 '~을 사랑하다'로 옮겨야 자연스럽다.

브리지의 첫머리는 이 **대상 + に**가 서술어 뒤로 빠진 도치문이다. 다음 예문처럼 뒤에 놓인 말을 앞으로 되돌려서 읽는다.

思ったより<ruby>好<rt>す</rt></ruby>きだった、あの<ruby>町<rt>まち</rt></ruby>が。
: 생각보다 좋아했다, 그 동네를.

### 5.3 글자나 소리가 같은 말

| 표기 | 읽기 | 뜻 |
| :-- | :-- | :-- |
| 苦い | にがい | (맛이) 쓰다 |
| 苦しい | くるしい | 괴롭다 |
| くれる | くれる | (나에게) 주다 |
| 暮れる | くれる | (날이) 저물다 |
| 止む | やむ | 그치다 |
| 止める | とめる | 멈추게 하다 |
| 側 | そば, がわ | 곁, ~쪽 |

### 5.4 뜻이 비슷한 말

| 단어 | 차이 |
| :-- | :-- |
| 帰る | 집이나 고향처럼 자기가 속한 곳으로 돌아가다 |
| 戻る | 원래 있던 자리나 상태로 되돌아가다 |
| ある | 사물이나 일이 있다 |
| いる | 사람이나 동물이 있다 |
| 知る | 정보를 얻어서 알게 되다 |
| わかる | 이해하다, 분간하다 |
| 匂い | 주로 좋은 냄새 |
| 臭い | 나쁜 냄새. 읽기는 똑같이 におい이다 |

### 5.5 자동사와 타동사

이 곡의 동사 가운데 짝이 있는 것을 함께 외워 두면 좋다.

| 자동사 | 타동사 |
| :-- | :-- |
| 残る (남다) | 残す (のこす, 남기다) |
| 隠れる (かくれる, 숨다) | 隠す (숨기다) |
| 戻る (되돌아가다) | 戻す (もどす, 되돌리다) |
| 離れる (떨어지다) | 離す (はなす, 떼다) |
| 傷つく (상처 입다) | 傷つける (きずつける, 상처 입히다) |
